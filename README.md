## 现在在做什么

我目前的工作集中在四条相互连接的线上：

- **AI 原生工作台**：对话式数据探索、因果分析、可审计的分析会话与权限边界。
- **个人知识系统**：用 Astro、Payload CMS 和 TypeScript 建设可持续维护的个人内容站。
- **移动端产品**：`female-solo-life-copilot` 正在进行 V0 真机联调，聚焦到家守护与日常报平安。
- **企业数据工程**：数据指标、SQL 诊断、任务调度和多源知识库处理。

我的原则很简单：**确定性逻辑负责可靠性，AI 负责理解、生成和辅助决策。**
